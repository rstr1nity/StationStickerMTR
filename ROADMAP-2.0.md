Не проверено в игре (последние правки, перед ними просить перезапуск):

2. Табло у платформы на конечной показывает «Посадки нет / No Boarding».
3. Указатель направлений: сторона с конечной — «Посадки нет», другая — конечная и следующие станции (для списка нужна линия из 3+ станций).
4. Новая пиктограмма «человек на лестнице» на навигационной табличке, стрелка влево и вправо.
5. Заметка после `||` в названиях маршрутов не показывается (`линия 1|line 1||in`).

Проверено пользователем в игре: табло прибытия (LED-шрифт, таймер, язык, иконки), звук один раз на поезд, навигационная табличка открывается кисточкой и находит пересадки.

Общее: основа `WideDisplayBlock` (ширина N клеток, невидимые `display_part`), корпус `WideDisplayRenderer` (скруглённый, подвес, двусторонний на потолке), холст `SlideCanvas`, LED-шрифт `LedFont`, пиктограммы `Pictograms`, названия по языку `StationNames`, поиск платформы `PlatformLocator`.

Табло прибытия:
- Сигнал `sounds/arrival_chime.ogg` (файл пользователя, моно) за 5 с до прибытия, после — пауза 20 с (`ArrivalChime`). Кисточка MTR включает/выключает (блокстейт `sound`).
- Конечная: показываются поезда, заканчивающие маршрут, если нет идущих дальше.

Навигационная табличка:
- Окно настройки только кисточкой MTR (`NavSignScreen`): шаблон, пересадка из списка, стрелка, пиктограмма.
- Настройки: пакет `NavSignSettingsPacket` (сервер проверяет расстояние ≤ 8 и `mayBuild`), синхронизация через `getUpdateTag/getUpdatePacket`.

## Что известно про MTR 4.0.3 (проверено по jar через javap и вики)

- Прибытия на клиенте: `ArrivalsCacheClient.INSTANCE.requestArrivals(platformIds)`. Обмен с сервером крутит `MainRenderer.render` каждый кадр — табло PIDS MTR для работы не нужны. Время сервера: `System.currentTimeMillis() + getMillisOffset()`; MTR уточняет время прибытия на лету (отсюда сглаживание таймера и пауза сигнала).
- Номер линии: `Route.getRouteNumber()` из `MinecraftClientData.routeIdMap`; в `SimplifiedRoute` номера нет.
- Пересадки: `SimplifiedRoutePlatform.forEach((цвет, названия))` — маршруты других цветов на любой платформе той же станции (скрытые исключены). `Station.getInterchangeStationToColorToRoutesMap` на клиенте в игре вернул пустой список — не используем.
- Станции с пересекающимися областями MTR считает связанными (`connectedStations`, `Station.intersecting`).
- Линия = маршруты одного цвета (точный hex). Два направления — два маршрута с одним цветом. Название: `линия 1|line 1||in` — до `||` языки, после — заметка только для дашборда ([вики: Dashboards](https://wiki.minecrafttransitrailway.com/mtr:dashboards)).
- Всё это внутренние классы `org.mtr.*`: при обновлении MTR проверять заново.

## Как работать

- Запуск: VS Code → «Запустить Minecraft (hot swap)» (F5). Hot swap подхватывает правки внутри методов; новые классы, поля, ресурсы — перезапуск.
- Пока игра запущена, ветку в основной папке не переключать (hot swap подсунет чужой код): 1.19.2 — через временный `git worktree` в scratchpad.
