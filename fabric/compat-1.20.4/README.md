# Experimental Fabric 1.20.4 client

Запуск из корня репозитория: Fabric-1.20.4-compatibility-test.cmd. В VS Code: задача «Fabric 1.20.4: compatibility test».

Сначала собирается существующий Fabric jar **1.20.1**, затем загружается в отдельный клиент Minecraft 1.20.4 с Fabric API и MTR 4.0.5 для 1.20.4. Исходники Station Sticker под 1.20.4 здесь не компилируются. Это проверка совместимости прежнего jar, а не готовый порт. Широкий диапазон в fabric.mod.json разрешает попытку загрузки, но не гарантирует совместимость API.

Сохранения из 1.19.2/1.20.1 не переносятся автоматически. Игра использует собственную папку compat-1.20.4/run-client. Лог: run-client/logs/latest.log; отчёты о падениях: run-client/crash-reports. Для воспроизводимой проверки не использовать hot swap, так как он мог бы подменить исходный jar.
