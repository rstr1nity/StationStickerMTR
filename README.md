# Station Sticker (аддон для MTR)

Аддон к [Minecraft Transit Railway](https://modrinth.com/mod/minecraft-transit-railway) для оформления станций и пассажирской навигации. Он читает станции, маршруты, прибытия поездов и выходы из MTR и добавляет:

- **Станционный стикер** (`station_sticker`) — табличка с названием станции и цветом линии. Ставится на стены, пол и потолок.
- **Схема линии** (`line_scheme`) — схема маршрутов, станций и пересадок у платформы. Направление меняется кисточкой MTR.
- **Табло прибытия** (`arrival_display`) — направление, номер линии, время до поезда и игровое время; на конечной показывает «Посадки нет». Есть звуковой сигнал прибытия.
- **Указатель направлений** (`direction_sign`) — конечные станции и ближайшие станции по обе стороны платформы с пересадками.
- **Навигационная табличка** (`nav_sign`) — шаблоны «Переход на линию» и «Выход в город» с настраиваемыми стрелками, пиктограммами и выходами станции MTR.
- **Вертикальная схема линии** (`vertical_line`, разработка 2.0.1 для 1.20.1) — напольный или настенный стенд 1×3. Кисточка открывает меню маршрута и значков; совместимые маршруты одного цвета показывают общие развилки; серые пройденные участки, цветная текущая станция, пересадки и дуги кольцевых линий.
- **Круглый стенд сети** (`network_map`, разработка 2.0.1 для 1.20.1) — двусторонняя схема всей публичной сети измерения на напольном стенде 3×4 блока. Кисточка переключает исходную и схематическую раскладку с окружностями простых кольцевых линий MTR.
- **Информационный экран** (`info_display`) — слайды с погодой в игре и сведениями о станции.

Ширину экранов и указателей можно настраивать от 2 до 8 блоков. Тексты экранов поддерживают русский и английский. В 2.0.1 для 1.20.1 добавлены настройка высоты подвесов, боковое крепление табло прибытия и направления обхода кольцевых маршрутов.

Текущая разработка — **2.0.1 Unreleased**, ветка `feature/2.0-displays`; новые возможности ещё не перенесены на 1.19.2. Клиент и сервер должны использовать одинаковую версию аддона (текущий протокол — 8).

## Сборка

Нужен JDK 17. Объявленный диапазон MTR в текущей ветке — `[4.0.0,4.1)`; это не означает проверку каждой версии диапазона. Актуальные значения — в `gradle.properties`.

```
./gradlew build
```

Jar появляется в `build/libs/`. MTR скачивается автоматически с Modrinth Maven, класть его вручную не нужно.

Чтобы jar после сборки сам копировался в папку `mods` тестовой игры, добавьте путь в **личный** `~/.gradle/gradle.properties` (не в репозиторий):

```properties
mods_dir_1.20.1=C:/Users/<user>/AppData/Roaming/.minecraft/mods
```

Кириллицу в пути нужно записывать `\u`-escape'ами: Gradle читает `.properties` в ISO-8859-1.

Запуск игры из среды разработки: `./gradlew runClient`.

### Правки без перезапуска игры (hot swap, VS Code)

Нужно расширение Extension Pack for Java.

1. В VS Code: Run and Debug → «Запустить Minecraft (hot swap)» → F5. VS Code сам запустит `./gradlew runClient --debug-jvm` и подключится, когда игра откроет порт 5005.
2. Если игра уже запущена вручную через `./gradlew runClient --debug-jvm`, выбрать «Подключиться к Minecraft (hot swap)».
3. После правки внутри метода и сохранения (Ctrl+S) класс подменяется в запущенной игре.

Подменяются только изменения внутри существующих методов. Новые методы, поля, классы и блоки требуют перезапуска.
Ресурсы обновляются без отладчика: `./gradlew processResources`, затем в игре F3+T (текстуры, модели, переводы) или `/reload` (лут, рецепты).

## Разработка

- `mc/1.20.1` — основная ветка, новая разработка идёт здесь (через ветки `feature/*`).
- `mc/1.19.2` — поддержка, изменения переносятся из `mc/1.20.1` через `git cherry-pick`.
- **Ветки разных версий MC между собой не мержатся.**
- Все версии (MC, Forge, MTR, мод) лежат в `gradle.properties`. В `mods.toml` и `pack.mcmeta` они подставляются при сборке.
- Релиз: тег `v<версия мода>+<версия MC>`, например `v1.1.0+1.20.1`. Изменения описываются в `CHANGELOG.md`.

## Проверки и план

- `./gradlew checkNetworkMapImage` — проверки шрифта, геометрии, раскладки и прямой загрузки текстур; создаёт рендеры в `build/`. Сохранённые сети пользователя проверяются только при наличии соответствующих локальных миров.
- `./gradlew runGameTestServer` — игровые проверки составных блоков и данных MTR.
- [Актуальный план и ограничения](ROADMAP-2.0.md), [журнал изменений](CHANGELOG.md), [старое техническое ревью](REVIEW.md).

У направлений одной линии MTR должен совпадать точный цвет; согласованные номера и названия обеспечивают единые подписи. Кольцевой маршрут отмечается настройкой самого MTR.
