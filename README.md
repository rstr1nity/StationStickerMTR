# Station Sticker (аддон для MTR)

Аддон к [Minecraft Transit Railway](https://modrinth.com/mod/minecraft-transit-railway), который добавляет:

- **Станционный стикер** (`station_sticker`) — табличка с названием станции и цветом линии, данные берутся из MTR автоматически. Ставится на стены, пол и потолок.
- **Схема линии** (`line_scheme`) — горизонтальный стикер со схемой линии для платформы. Направление стрелки переключается кисточкой MTR.

## Поддерживаемые версии

| Minecraft | Загрузчик | MTR | Ветка |
|---|---|---|---|
| 1.20.1 | Forge 47+ | 4.0.x (от 4.0.3) | `mc/1.20.1` |
| 1.19.2 | Forge 43.4.6+ | 4.0.x (от 4.0.3) | `mc/1.19.2` |

## Сборка

Нужен JDK 17.

```
./gradlew build
```

Jar появляется в `build/libs/`. MTR скачивается автоматически с Modrinth Maven, класть его вручную не нужно.

Чтобы jar после сборки сам копировался в папку `mods` тестовой игры, добавьте путь в **личный** `~/.gradle/gradle.properties` (не в репозиторий):

```properties
mods_dir_1.20.1=C:/Users/<user>/AppData/Roaming/.minecraft/mods
```

Кириллицу в пути нужно записывать `\u`-escape'ами: Gradle читает `.properties` в ISO-8859-1.

Запуск игры из среды разработки: `./gradlew runClient`.

### Правки без перезапуска игры (hot swap, VS Code)

Нужно расширение Extension Pack for Java.

1. В терминале: `./gradlew runClient --debug-jvm`. Игра стартует на паузе и ждёт отладчик.
2. В VS Code: Run and Debug → «Подключиться к Minecraft (hot swap)» → F5.
3. После правки внутри метода и сохранения (Ctrl+S) класс подменяется в запущенной игре.

Подменяются только изменения внутри существующих методов. Новые методы, поля, классы и блоки требуют перезапуска.
Ресурсы обновляются без отладчика: `./gradlew processResources`, затем в игре F3+T (текстуры, модели, переводы) или `/reload` (лут, рецепты).

## Разработка

- `mc/1.20.1` — основная ветка, новая разработка идёт здесь (через ветки `feature/*`).
- `mc/1.19.2` — поддержка, изменения переносятся из `mc/1.20.1` через `git cherry-pick`.
- **Ветки разных версий MC между собой не мержатся.**
- Все версии (MC, Forge, MTR, мод) лежат в `gradle.properties`. В `mods.toml` и `pack.mcmeta` они подставляются при сборке.
- Релиз: тег `v<версия мода>+<версия MC>`, например `v1.1.0+1.20.1`. Изменения описываются в `CHANGELOG.md`.
