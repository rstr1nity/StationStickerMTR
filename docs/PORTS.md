# Forge и Fabric: сборка 2.1.0

Одна ветка — одна версия Minecraft. В текущей ветке: **1.19.2**. Ветки разных MC не объединять. Forge использует основной проект; Fabric — отдельную сборку `fabric/`, которая берёт общие исходники и ресурсы из основного проекта этой же ветки. Дублировать схемы, текстуры и алгоритмы для загрузчиков не требуется.

## Сборка

Java 17. Версии зависимостей заданы в корневом `gradle.properties`.

- Forge: `./gradlew build` из корня.
- Fabric: `cd fabric`, затем `./gradlew build` (PowerShell: `.\gradlew build`).
- Forge jar: `build/libs/StationStickerMTR-2.1.0+1.19.2.jar`.
- Fabric jar: `fabric/build/libs/StationStickerMTR-Fabric-2.1.0+1.19.2.jar`.

У Fabric свой Gradle/Loom. Скрипт запуска использует существующий wrapper jar основного проекта, копируя его и настройки Fabric в игнорируемую папку build/wrapper. Второй wrapper jar в репозиторий не добавляется.

## Как устроен порт

`prepareSharedSources` создаёт игнорируемые исходники Fabric из `../src/main/java`, заменяя только привязки к загрузчику. Точки загрузки, клиентские события, регистрация и сетевой транспорт реализованы в `fabric/src/main/java`. Исходный Forge-код не меняется при такой сборке. Общая геометрия, названия, состояния блоков, NBT и ресурсы остаются одними и теми же. Рендер вне основного блока обеспечивают существующие shouldRenderOffScreen.

Сетевые пакеты Fabric используют идентификаторы v8 и выполняют обработку на основном потоке. Рецепты Fabric используют собственные теги ингредиентов Station Sticker вместо тегов Forge; стандартные красители, железо, стеклянные панели и светокаменная пыль включены явно.

Проверки прав, расстояния и допустимых настроек сохранены из общего кода. Для сервера и клиента использовать одинаковую версию аддона и один загрузчик; совместимость Forge-клиента с Fabric-сервером не заявляется.

## Установка

Для Fabric нужны Fabric Loader, Fabric API и **Fabric-версия MTR 4.0.5** соответствующей версии Minecraft. Для Forge — Forge и соответствующая Forge-версия MTR (в 1.19.2 сохранена проверенная зависимость 4.0.3, в 1.20.1 — 4.0.5). Не помещать Forge и Fabric jar Station Sticker в одну установку. Существующие игровые миры новейшей версии не открывать старой версией Minecraft.

## Проверки

- Forge 1.19.2: сборка, рендеры схем, пиксели/прозрачность, legacy Unicode-шрифт, все 7 GameTest. После остановки GameTest повторяется отдельный сбой Gradle daemon; обычный build успешен.
- Fabric: обе версии собираются; для каждой запускается отдельный тестовый сервер с проверкой 8 блоков/сущностей, 8 рецептов с непустыми ингредиентами и roundtrip пакета настроек.
- Реальный клиент: регистрация 8 рендереров, загрузка шрифтов Minecraft и динамической текстуры. Подтверждение отображения всех меню и блоков пользователем в рабочем мире ещё требуется.

Опциональные проверки: `./gradlew runServer -Psmoke=true --args=nogui` и `./gradlew runClient -PsmokeClient=true` из fabric. Они предназначены для отдельных тестовых папок `fabric/run-server` и `fabric/run-client`; штатный запуск без этих параметров не выполняет проверки и не закрывается автоматически. Для сервера нужен собственный eula.txt. Тестовый клиент закрывается после проверки ресурсов; сервер — после проверки блоков.

Релиз 2.1.0 остаётся Unreleased: сборка и порт не означают публикацию на площадках.
